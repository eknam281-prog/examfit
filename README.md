# EXAMFIT — 중국어 전공 학습·시험 대비 웹앱

핏찹이와 함께 성장하는 **중국어 전공 대학생용 게임형 학습 · AI 시험 대비** 웹앱입니다. (해커톤 출품작)

## 개발 배경

중국어 전공 수업은 한자·병음·성조를 매일 조금씩 익히는 **일상 학습**과, 교수님마다 출제 방식이 다른 **시험 대비**를 따로 챙겨야 합니다. 강의자료는 PDF(때로는 스캔본, 손글씨 필기 포함)로 흩어져 있고, 학습 앱은 시험 범위를 반영하지 못하며, 시험 범위 요약 도구는 매일의 습관 형성을 돕지 못합니다.
EXAMFIT은 이 둘을 하나의 흐름으로 묶고, 캐릭터 '핏찹이'의 성장으로 학습을 꾸준히 이어 가도록 설계했습니다.

## 타깃 사용자

- 중국어 전공(또는 중국어 수업을 듣는) 대학생
- 강의자료 PDF로 시험을 준비하며, 교수님의 출제 방식(객관식·서술형·구술 등)에 맞춰 연습하고 싶은 사람
- 매일 짧게라도 단어·듣기·회화·한자 쓰기를 이어 가고 싶은 사람

## 핵심 기능

### 일상 중국어 (매일 학습)
- **핏찹이 이름 짓기 · 실력 진단**: 최초 접속 시 캐릭터 이름 설정 → 자기 평가 + 5문제 진단으로 시작 수준(입문~고급) 추천. 진단은 참고용이며 HSK 급수를 판정하지 않습니다.
- **오늘의 학습 설정**: 단어 수(10/20/30/직접 입력)와 회화 주제 선택. 회화 문장 수 = ⌈단어 수 ÷ 2⌉, 최종 퀴즈 수와 항상 일치.
- **연결형 4단계**: 단어·표현 → 듣기 → 회화 → 한자 쓰기. 같은 날 배운 단어가 모든 단계에서 재사용되며, 이전 단계를 마쳐야 다음 단계가 열립니다(만점 불필요, 오답은 복습 목록에 저장).
- **회화 따라 말하기**: 브라우저 음성 인식(zh-CN)으로 말한 문장을 목표 문장과 글자 단위로 비교. 발음·성조 점수는 만들지 않으며, 마이크 없이 '평가 없이 학습 완료'도 가능.
- **한자 쓰기**: Hanzi Writer 획순 애니메이션·따라 쓰기, 발음 반복 듣기, 힌트 없는 최종 쓰기 퀴즈(제출 후에만 정답 공개).

### 시험 대비
- **PDF 자료 처리**: pdf.js 텍스트 추출 + 자동 품질 점검(사용 가능/확인 권장/실패), 페이지별 원본 열람·수정·확정.
- **스캔 PDF 인식**: 텍스트가 없는 페이지를 FactChat 비전 모델로 인식(사용자가 페이지를 선택하고 승인한 뒤에만 호출).
- **AI 예상문제 생성**: 업로드한 자료에 근거한 객관식(5지선다)·서술형·말하기 문제. 근거 원문과 출처(파일·쪽)를 검증하고, 근거를 확인할 수 없는 문제는 제외.
- **서술형 보완 피드백**: 점수 없이 잘 쓴 부분·보완할 부분·개선 예시 제공.
- **AI 구술시험**: 중국어 질문 → 마이크 답변 → 한국어 교정 피드백, 문제당 최초 1회 + 재시도 2회.

### 기록 · 설정
- 캐릭터 레벨·XP, 학습 달력(4단계 완료일엔 핏찹이), 연속 학습, 복습 목록
- 시작 수준 변경 · 재진단, 이름 변경
- JSON 백업/복원, 단계별 초기화(오늘의 학습 / 실력 설정 / 전체)

## 기술 스택

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- pdf.js(`pdfjs-dist`) — PDF 텍스트 추출·페이지 렌더링
- Hanzi Writer — 한자 획순 학습
- 브라우저 Web Speech API — TTS(`speechSynthesis`)와 음성 인식(`SpeechRecognition`)
- FactChat 게이트웨이(OpenAI 호환) — 문제 생성·피드백·스캔 인식·실시간 음성(서버에서만 호출)
- 데이터 저장: 브라우저 `localStorage` + `IndexedDB`(PDF·추출 텍스트)

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 값 채우기(아래 표). Windows PowerShell: Copy-Item .env.example .env.local
npm run dev                  # http://localhost:3000
```

타입 검사·프로덕션 빌드:

```bash
npm run typecheck
npm run build && npm run start
```

### 환경변수(`.env.local`, 서버 전용 — 커밋 금지)

| 이름 | 설명 |
|---|---|
| `FACTCHAT_API_KEY` | FactChat API 키(서버에서만 사용, 브라우저로 전달되지 않음) |
| `FACTCHAT_API_BASE_URL` | 예: `https://factchat-cloud.mindlogic.ai/v1/gateway` |
| `FACTCHAT_MODEL` | 문제 생성·피드백용 텍스트 모델 ID |
| `FACTCHAT_API_FORMAT` | `openai-chat` |
| `FACTCHAT_VISION_MODEL` | 스캔 PDF 인식용(이미지 입력 지원 모델) |
| `FACTCHAT_REALTIME_MODEL` | AI 구술시험용 실시간 음성 모델 |
| `EXAMFIT_AI_ENABLED` | `true`일 때만 AI 서버 API가 동작(기본 꺼짐) |

AI 환경변수가 없어도 일상 중국어 학습, PDF 추출·검수, 기록·설정은 모두 동작합니다.

## 제한사항

- **데이터는 이 브라우저에만 저장**됩니다. 로그인·계정·기기 간 동기화가 없으며, 백업 파일로만 옮길 수 있습니다. 백업에는 PDF 원본·OCR 자료(IndexedDB)가 포함되지 않습니다.
- 학습 콘텐츠는 직접 작성한 소규모 고정 은행(단어 64개·문장 40개·한자 119자)이라 단어 64개를 넘는 설정은 가능한 수량으로 조정됩니다.
- TTS는 브라우저 내장 음성이라 기기마다 음질·성조가 다르고, 중국어 음성이 없는 기기에서는 소리가 나지 않을 수 있습니다.
- 음성 인식은 Chrome·Edge·Safari 계열에서 동작하며 Firefox 등은 미지원입니다. 인식 결과 비교는 발음·성조 점수가 아닙니다. Chrome 계열은 인식을 위해 음성이 제공사 서버로 전송될 수 있습니다.
- 한자 최종 퀴즈의 획 판정은 위치·방향·순서를 근사 비교한 것으로, 전문 손글씨 평가가 아닙니다.
- AI 문제 생성·스캔 인식·구술시험은 AI 오류 가능성이 있고(특히 병음·성조·손글씨), 미검수 결과는 사용자가 확인한 뒤에만 문제 생성에 쓰입니다.
- AI 기능은 호출마다 FactChat 크레딧이 사용되며 정확한 비용은 알 수 없습니다. 서버 측 호출 제한은 인스턴스 단위(메모리)라 서버리스 환경에서는 완전한 남용 방지가 아닙니다.
- 일부 기능(실제 브라우저의 마이크·TTS·필기 입력 등)은 개발 중 자동 시험만 거쳤고 기기별 확인이 더 필요합니다.

## 보안·운영 메모

- API 키는 서버 환경변수로만 읽으며 저장소에 포함되지 않습니다(`.env*`는 `.gitignore`, `.env.example`만 추적).
- 공개 배포 시 AI 기능을 시연하는 기간에만 `EXAMFIT_AI_ENABLED=true`로 설정하고, 호스팅 쪽 사용량 한도를 함께 설정하는 것을 권장합니다.
